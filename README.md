# Nullius Transport Drones Continued Compatibility

Compatibility mod for using [Transport Drones Continued Fixed](https://mods.factorio.com/mod/Transport_Drones_Continued_Fixed) with [Nullius](https://mods.factorio.com/mod/nullius).

## Scope

This mod ports Nullius’ historical Transport Drones compatibility to Factorio 2.0 and the `Transport_Drones_Continued_Fixed` fork.

It adjusts Transport Drones recipes, technologies, depots, roads, and generated request recipes so they fit into the Nullius progression.

## Attribution

Almost all of the code and most of the compatibility design comes from the original Nullius codebase, which previously supported Transport Drones.
This mod repackages and updates that work for the current Transport Drones fork.

Additional changes here include:

- Support for `Transport_Drones_Continued_Fixed`.
- Updates for Factorio 2.0 prototype changes.
- Tech tree adjustments for the newer Transport Drones fork.
- An optional early/easy mode setting.

## Easy Mode

Easy mode is enabled by default.

It moves Transport Drones earlier in the Nullius tech tree and combines some depot unlocks so the system becomes usable sooner.

If you prefer progression closer to the original Nullius Transport Drones integration, disable the startup setting:

`Early transport drones`
